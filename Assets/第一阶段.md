> 点击开始后，音乐播放，游戏状态变为 `Playing`。

## 第 4 步：创建音符数据结构和测试谱面

目标：

> 先用代码写死一组测试谱面数据。

主要内容：

1. 创建 `WeightType` 枚举。
2. 创建 `NoteData` 数据类。
3. 给每个音符设置：

   * 出现时间 `time`
   * 轨道编号 `lane`
   * 重量类型 `weightType`
4. 写一组 30 秒左右的测试谱面。
5. 在控制台打印谱面，确认数据正常。

完成后效果：

> 项目里已经有一组可以用于生成音符的谱面数据。

---

## 第 5 步：创建 3D 音符预制体

目标：

> 做出第一版可以显示的 3D 音符。

主要内容：

1. 创建一个基础 3D 物体作为音符。
2. 命名为 `NotePrefab`。
3. 添加 `Note.cs`。
4. 给不同重量类型设置不同颜色或大小。
5. 保存为 Prefab。
6. 暂时不做复杂模型。

第一版音符建议：

| 类型      | 表现              |
| --------- | ----------------- |
| Normal    | 蓝白色小球        |
| Heavy     | 红橙色较大球/方块 |
| Light     | 青色较小球        |
| Stabilize | 绿色或金色球      |

完成后效果：

> 场景中可以看到不同类型的 3D 音符。

---

## 第 6 步：实现音符生成系统

目标：

> 根据谱面，在正确时间提前生成音符。

主要内容：

1. 创建 `NoteSpawner.cs`。
2. 设置 `notePrefab`。
3. 设置 4 个 `spawnPoints`。
4. 设置 4 个 `judgePoints`。
5. 设置 `spawnAheadTime`，例如 2 秒。
6. 根据当前音乐时间生成即将出现的音符。
7. 把生成的音符放到 `NoteRoot` 下。

完成后效果：

> 播放音乐后，音符会按照谱面依次生成。

---

## 第 7 步：实现音符飞行

目标：

> 音符从生成点沿轨道飞向判定点。

主要内容：

1. 在 `Note.cs` 中保存：

   * `hitTime`
   * `lane`
   * `weightType`
   * `spawnPosition`
   * `judgePoint`
   * `spawnAheadTime`
2. 根据当前音乐时间计算音符进度。
3. 使用 `Vector3.Lerp()` 移动音符。
4. 确保音符在 `hitTime` 时正好到达判定点。
5. 超过判定时间后标记为 Miss。

完成后效果：

> 音符能稳定地沿 3D 轨道飞向判定线。

---

## 第 8 步：实现玩家输入系统

目标：

> 玩家可以按 A / S / D / F 击打对应轨道的音符。

主要内容：

1. 创建 `RhythmInput.cs`。
2. 检测四个按键：

   * A
   * S
   * D
   * F
3. 将按键转换成轨道编号。
4. 在对应轨道寻找最近的可判定音符。
5. 将该音符交给 `JudgeSystem` 处理。

完成后效果：

> 玩家按键时，系统能找到对应轨道上最接近判定时间的音符。

---

## 第 9 步：实现判定系统

目标：

> 根据玩家按键时间判断 Perfect / Good / Bad / Miss。

主要内容：

1. 创建 `JudgeSystem.cs`。
2. 创建 `JudgeResult` 枚举。
3. 设置判定窗口：

   * Perfect：±0.05 秒
   * Good：±0.10 秒
   * Bad：±0.15 秒
   * Miss：超过 ±0.15 秒
4. 计算当前音乐时间和音符 `hitTime` 的差值。
5. 返回对应判定结果。
6. 显示判定文字。
7. 命中音符后销毁音符。
8. 漏掉音符后判定 Miss。

完成后效果：

> 按准显示 Perfect，偏一点显示 Good / Bad，漏掉显示 Miss。

---

## 第 10 步：实现分数和连击

目标：

> 玩家操作后能得到分数和连击反馈。

主要内容：

1. 创建 `ScoreManager.cs`。
2. 根据判定结果加分。
3. Perfect / Good / Bad 增加连击。
4. Miss 清空连击。
5. 记录最大连击。
6. 更新 `ScoreText`。
7. 更新 `ComboText`。

分数建议：

| 判定    | 分数 |
| ------- | ---- |
| Perfect | 1000 |
| Good    | 700  |
| Bad     | 300  |
| Miss    | 0    |

完成后效果：

> 分数和连击会随着玩家表现变化。

---

## 第 11 步：实现判定线重量效果

目标：

> 不同音符击中后，会改变判定线位置。

主要内容：

1. 创建 `JudgeLineController.cs`。
2. 保存判定线初始位置。
3. 保存 `offsetY`。
4. Heavy 音符让判定线下沉。
5. Light 音符让判定线上浮。
6. Stabilize 音符让判定线回正。
7. 每帧更新 `JudgeLine` 的位置。
8. 同步更新 `JudgePointRoot` 的位置。

偏移建议：

| 音符类型  | 效果              |
| --------- | ----------------- |
| Normal    | 不偏移            |
| Heavy     | `offsetY -= 0.25` |
| Light     | `offsetY += 0.18` |
| Stabilize | `offsetY *= 0.4`  |

完成后效果：

> 重音符像是在砸判定线，轻音符像是在托起判定线。

---

## 第 12 步：实现判定线自动回正

目标：

> 判定线被影响后，会自然回弹到默认位置。

主要内容：

1. 在 `JudgeLineController` 中添加 `velocityY`。
2. 添加 `springForce`。
3. 添加 `damping`。
4. 每帧计算回正力。
5. 限制最大偏移。
6. 让判定线平滑恢复。

完成后效果：

> 判定线不会僵硬地瞬间复位，而是有弹性地回到中心。

---

## 第 13 步：实现稳定度系统

目标：

> 用稳定度作为游戏生命值。

主要内容：

1. 创建 `StabilitySystem.cs`。
2. 设置初始稳定度为 100。
3. 根据判定结果改变稳定度。
4. 判定线偏移过大时持续扣稳定度。
5. 更新 `StabilitySlider`。
6. 稳定度归零时调用 `FailGame()`。

稳定度建议：

| 情况              | 变化 |
| ----------------- | ---- |
| Perfect           | +1   |
| Good              | 0    |
| Bad               | -3   |
| Miss              | -8   |
| Heavy Miss        | -15  |
| Stabilize Perfect | +8   |

完成后效果：

> 玩家失误或判定线失控时，稳定度下降；稳定度归零后失败。

---

## 第 14 步：实现 Space 主动校准

建议规则：

| 校准效果               | `offsetY *= 0.5`   |
| 速度削弱               | `velocityY *= 0.3` |

完成后效果：

> 玩家在判定线失控时，可以按 Space 主动把局面拉回来。
